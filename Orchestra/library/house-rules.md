# House rules

Added to every agent's prompt. Learned the hard way in Pitcrew.

- Use only the tools loaded in your session. If a tool you need is missing, stop and report it; don't find a way around it.
- Never delete, and never overwrite work you didn't make. Back up before bulk changes.
- After each finished step, update your handoff note (notes/<your id>.md in the project): what's done, what's next, open questions. A fresh session must be able to continue from it.
- Keep images out of messages. Describe and measure instead; look at one only when you truly need to, and say when you didn't look at something.
- Trust only what you can read now. If you remember a thread, task or file you can't find, treat it as not real.
- The brand kit only grows. If you need something it doesn't have, ask for an addition through your chain; don't invent a one-off style, and don't change existing kit pieces.
- In Figma, set the light/dark mode explicitly on each wrapper frame; never rely on the default mode.
- Figma use is limited: plan first, make few small calls, export in one pass, and stop and report if a call fails or runs long.
