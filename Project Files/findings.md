# Findings from the app walkthrough

A running list from the owner's pass through the whole app, to be fixed in a later pass (by a different model). One finding per line group. Keep each one concrete: where it is, what is wrong, what it should do.

**How to use this file**
- Add findings as `- [ ]` items under the screen they belong to.
- Tick `[x]` when fixed, with the commit or branch.
- Severity (optional): `bug` (broken), `ux` (confusing or clumsy), `polish` (looks off), `idea` (new).
- Before fixing, read `AGENTS.md`: one concern per branch, stage files by name.
