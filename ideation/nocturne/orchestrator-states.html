Easing and timing

The face uses a calmer curve than the rest of the UI, cubic-bezier(.45,.05,.25,1). State changes ease over about a second with a slow in-out curve, so nothing snaps or jolts. Impulses (a key, a send) are soft springs that die away over a second or two. Loops are linear only where something spins.

One new token

Error needs a colour the Nocturne set doesn't have: status/error #FF5A5F. The shell also drains to graphite, so the state still reads without colour.

In the app

<OrchestratorFace state size />: one WebGL fragment shader for the liquid (metaball body, refraction, fresnel rim, domain-warped interior) plus an SVG layer for the ring and badge. States only change shader inputs, eased over about a second. Without WebGL it falls back to the flat SVG orb; reduced motion freezes the liquid and keeps the colour.
